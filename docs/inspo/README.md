The brief is **the vibe of diplosrunclub.com, done better**, for TONY Skate Club. That means a
Nashville street/freeride pro and the group skates he started. It is not a shop and not an event
ticketer.

## What this board says about TONY Skate Club
1. **The motif already exists.** The GIF's stacked TONY ladder matches Palace's text ladder and
   reads like a gig poster. Make it the one signature and carry it through the site.
2. **Photos and video lead, copy follows.** Every skate reference puts footage first. Tony's
   folder has 245 photos and 3 clips, so the site can be image-dominant.
3. **Bright ground, not black.** Every skate site here is dark or grey. The GIF is white concrete,
   sky and parking-garage fins. Staying light is how this avoids looking like the rest.
4. **One flat colour field per section,** like Fantom, but restricted to the GIF's own colours
   (Tony's orange pants and beanie) instead of a rainbow.
5. **Voice:** short, local, a little funny, like the Rollerblade Q&A. No marketing filler.
