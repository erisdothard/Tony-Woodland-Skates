# Tony Woodland Skates

Website for Tony Woodland Skates, built with [Next.js](https://nextjs.org) and Tailwind CSS, deployed on [Vercel](https://vercel.com).

## Local development

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Scripts

| Command      | What it does                      |
| ------------ | --------------------------------- |
| `pnpm dev`   | Start the dev server              |
| `pnpm build` | Production build                  |
| `pnpm start` | Serve the production build        |
| `pnpm lint`  | Run ESLint                        |

## Deployment

The `main` branch deploys to production on Vercel. Every pull request gets a preview deployment.

To connect the project for the first time: go to https://vercel.com/new, import `erisdothard/Tony-Woodland-Skates`, keep the detected Next.js defaults, and click Deploy.
